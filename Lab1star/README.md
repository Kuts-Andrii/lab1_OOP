# MyExcel — лабораторна робота №1* (ООП), варіант 2

**Розробка програми для роботи з електронними таблицями (аналіз та обчислення виразів), що включає роботу з Google Drive.**

Виконав: студент групи К-28 Куць Андрій Станіславович, ФКНК КНУ імені Тараса Шевченка.

## Варіант 2

Набори операцій **1, 2, 3, 5**:

| № | Операції | Реалізація |
|---|----------|------------|
| 1 | `+`, `-`, `*`, `/` (бінарні) | `/` — ділення націло з відкиданням дробової частини (`-7 / 2 = -3`) |
| 2 | `mod`, `div` | `div` — ділення з округленням униз (`-7 div 2 = -4`), `mod` — остача, узгоджена з `div` (`-7 mod 3 = 2`) |
| 3 | `+`, `-` (унарні) | `-A1`, `--5`, `2 * -3` |
| 5 | `inc`, `dec` | `inc(x) = x + 1`, `dec(x) = x - 1` |

Варіант 2 належить до варіантів 1–19, тому вирази **арифметичні**: значення — ціле число. Числа мають **довільну довжину** (`System.Numerics.BigInteger`).

## Можливості

- Український інтерфейс: головне меню, панель інструментів, рядок формул, рядок стану, сторінка довідки (F1), «Про програму».
- Введення та редагування виразів у клітинках і в рядку формул; автоматичний перерахунок усіх залежних клітинок.
- Два режими відображення: **ВИРАЗ** / **ЗНАЧЕННЯ**.
- Два етапи обробки виразу: **синтаксична перевірка з локалізацією помилки** (номер позиції) та **обчислення значення**.
- Посилання на клітинки (`A1`, `ab12`, …), порожня клітинка = 0.
- Виявлення **циклічних посилань** (алгоритм Тар'яна), ділення на нуль, посилань на неіснуючі клітинки, поширення помилок на залежні клітинки. Опис помилки — у підказці клітинки та в рядку стану.
- Додавання та видалення рядків/стовпчиків з попередженням, якщо видалення зачіпає дані або посилання.
- Збереження/відкриття файлів у власному форматі `*.myexcel` (JSON).
- **Google Drive**: вхід в обліковий запис через OAuth 2.0, збереження, відкриття, видалення таблиць у папці застосунку (`appDataFolder`), вихід з облікового запису.
- Попередження про незбережені зміни (нова таблиця, відкриття, вихід).
- Модульні тести ядра (xUnit).

## Структура рішення

```
MyExcel.sln
├── MyExcel.Core/                 бібліотека класів (логіка, без UI)
│   ├── Grammar/LabCalculator.g4  граматика ANTLR (варіант 2)
│   ├── Parsing/
│   │   ├── ExpressionParser.cs   етап 1: лексичний і синтаксичний аналіз
│   │   ├── LexerErrorListener.cs, ParserErrorListener.cs  локалізація помилок
│   │   ├── ReferenceCollector.cs збирання посилань для графа залежностей
│   │   └── EvaluationVisitor.cs  етап 2: обчислення (шаблон Visitor)
│   ├── CellAddress.cs            адреса клітинки, назви стовпчиків A..ZZ
│   ├── Cell.cs, CellValue.cs, CellError.cs  клітинка, значення, помилки
│   ├── Spreadsheet.cs            модель таблиці, перерахунок
│   ├── CycleDetector.cs          пошук циклів (алгоритм Тар'яна)
│   ├── IntegerArithmetic.cs      /, div, mod для BigInteger
│   ├── Calculator.cs             обчислення окремого виразу
│   └── Serialization/SpreadsheetSerializer.cs  формат *.myexcel
├── MyExcelMAUIApp/               застосунок .NET MAUI (Windows)
│   ├── MainPage.xaml(.cs)        головне вікно з таблицею
│   ├── Platforms/Windows/        платформний код Windows
│   ├── HelpPage.xaml(.cs)        довідка користувача
│   ├── Services/SpreadsheetFileService.cs   локальні файли
│   ├── Services/GoogleDriveService.cs       Google Drive
│   └── Resources/Raw/            сюди кладеться client_secrets.json
├── MyExcel.Core.Tests/           модульні тести (xUnit)
└── docs/client_secrets.example.json
```

**Чому немає «магічної кнопки».** Обробники подій у `MainPage` лише передають дані моделі `Spreadsheet` та сервісам і оновлюють відображення. Аналіз і обчислення виразів, граф залежностей, цикли, серіалізація — в окремій бібліотеці `MyExcel.Core`, яка не знає про інтерфейс і покрита тестами. Робота з файлами та Google Drive винесена в окремі класи-сервіси.

## Граматика (БНФ)

```
<вираз-клітинки> ::= [ "=" ] <вираз>
<вираз>          ::= <вираз> ( "+" | "-" ) <доданок> | <доданок>
<доданок>        ::= <доданок> ( "*" | "/" | "div" | "mod" ) <множник> | <множник>
<множник>        ::= ( "+" | "-" ) <множник> | <первинний>
<первинний>      ::= <число> | <клітинка> | "(" <вираз> ")"
                   | "inc" "(" <вираз> ")" | "dec" "(" <вираз> ")"
<число>          ::= <цифра> { <цифра> }
<клітинка>       ::= <літера> { <літера> } <ненульова-цифра> { <цифра> }
```

У файлі `LabCalculator.g4` пріоритети задано порядком альтернатив ліворекурсивного правила `expression` (ANTLR 4). Ключові слова `mod`, `div`, `inc`, `dec` нечутливі до регістру.

## Запуск

Потрібно: Visual Studio 2022 (17.14+) або 2026 з **.NET 10 SDK**. У Visual Studio Installer мають бути встановлені:
- робоче навантаження **«Розробка мультиплатформних застосунків .NET (.NET MAUI)»**;
- окремий компонент **«MSVC … C++ x64/x86 build tools (Latest)»** — без нього збирання WinUI завершується помилкою `GetLatestMSVCVersion`.

1. Відкрийте `MyExcel.sln`.
2. Стартовий проєкт — `MyExcelMAUIApp`, ціль — **Windows Machine**.
3. Запустіть (F5). Пакети NuGet (`Antlr4.Runtime`, `Antlr4.CodeGenerator` 4.6.6, `Google.Apis.*`) відновляться автоматично; Java не потрібна — ANTLR генерує класи `LabCalculatorLexer`, `LabCalculatorParser`, `LabCalculatorBaseVisitor` під час збирання.

Тести: **Test → Run All Tests** або `dotnet test MyExcel.Core.Tests`.



## Налаштування Google Drive

Згідно з «Додатком 1. Інтеграція з сервісами Google»:

1. На https://console.cloud.google.com/ створіть проєкт (Location — *No organization*).
2. **APIs & Services → Library**: знайдіть **Google Drive API** і натисніть **Enable**.
3. **OAuth consent screen**: тип *External*, вкажіть назву застосунку та свою пошту; у *Scopes* додайте `https://www.googleapis.com/auth/drive.appdata`; у *Test users* додайте свою адресу Gmail.
4. **Credentials → Create credentials → OAuth client ID**, тип **Desktop app**. Завантажте JSON.
5. Перейменуйте файл на `client_secrets.json` і покладіть у `MyExcelMAUIApp/Resources/Raw/` (приклад вмісту — `docs/client_secrets.example.json`). Перезберіть проєкт.

Під час першого збереження чи відкриття з Google Drive відкриється браузер із входом у Google. Токен зберігається в `%LOCALAPPDATA%` застосунку, тож повторно входити не потрібно (поки не натиснете «Вийти з облікового запису Google»). Файли зберігаються в прихованій папці застосунку на Google Drive і не захаращують ваш диск. `client_secrets.json` додано в `.gitignore` — не публікуйте його.

Без `client_secrets.json` решта програми працює, а при спробі звернутися до Google Drive з'являється зрозуміле повідомлення.

## Можливі проблеми

- **`Resources/Raw` порожня, Google Drive недоступний** — див. розділ «Налаштування Google Drive».
- **Помилка `access_denied` під час входу** — ваша адреса не додана в *Test users* на OAuth consent screen.
